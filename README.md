# Job-Portal-Automation-Testing-Using-Playwright
Project Overview
This project focuses on automating the functional testing of a Job Portal Web Application using Playwright and JavaScript. The purpose is to verify that the major features of the application work correctly through automated test cases.

Objectives
To automate web application testing using Playwright.
To verify login and registration functionality.
To test job search and job application features.
To verify profile updating and logout functionality.
To check dashboard access after logout.
To evaluate test results and identify functional issues.

Technologies Used
Frontend: React.js
Programming Language: JavaScript
Automation Testing Tool: Playwright
Runtime Environment: Node.js
Development Server: Vite
Code Editor: Visual Studio Code
Browser: Chromium

Features Tested
Job portal homepage verification
Login with valid credentials
Rejection of invalid login credentials
Registration password mismatch validation
New user registration
Job search by location
Display of all jobs when the search field is empty
Job application submission
